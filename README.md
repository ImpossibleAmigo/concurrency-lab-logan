# Паралельний аналізатор журналу запитів

Практична робота № 1 з дисципліни «Паралельні та багатопоточні обчислення».
Аналізатор логів, що будує звіт за кількістю запитів, розподілом статусів, перцентилями затримок (p50, p95, p99) та найбільш навантаженими ендпоінтами.

## Збирання проєкту

### Режим Release (для замірів продуктивності)
\`\`\`bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
\`\`\`

### Режим Debug із ThreadSanitizer (для пошуку гонок даних)
\`\`\`bash
cmake -S . -B build-tsan -DCMAKE_BUILD_TYPE=Debug \
      -DCMAKE_CXX_FLAGS="-fsanitize=thread -g -O1" \
      -DCMAKE_EXE_LINKER_FLAGS="-fsanitize=thread"
cmake --build build-tsan -j
\`\`\`

## Параметри командного рядка

Загальні параметри для всіх програм:
* \`--lines N\` — кількість рядків журналу для обробки (типово 5000000).
* \`--seed S\` — seed для генератора (типово 2026).
* \`--runs R\` — кількість вимірювальних прогонів (типово 5).
* \`--report\` — виведення повного канонічного звіту в консоль.

## Запуск програм (Етапи)

### Етап 0: Послідовна версія
\`\`\`bash
./build/stage0_seq --lines 1000000 --report
\`\`\`
