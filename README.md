# Concurrency Lab: Log Analyzer (C++20)

Лабораторна робота з паралельного програмування на C++20. Мета проєкту — послідовна розробка та оптимізація багатопотокового аналізатора логів із використанням сучасних примітивів синхронизації (`std::jthread`, `std::mutex`, `std::condition_variable`, `std::future`, `std::atomic`).

---

## Структура проєкту
Проєкт складається з чотирьох послідовних етапів:
* **Етап 0 (`stage0_seq.cpp`)**: Базова послідовна реалізація (еталон для перевірки контрольних сум).
* **Етап 1 (`stage1_threads.cpp`)**: Паралельна обробка з ручним розбиттям буфера на частини та різними режимами синхронизації (`local`, `atomic`, `race`).
* **Етап 2 (`stage2_pipeline.cpp`)**: Конвеєрна архітектура «виробник — споживачі» на основі потокобезпечної обмеженої черги (`BoundedQueue`).
* **Етап 3 (`stage3_pool.cpp`)**: Масштабований пул потоків (`ThreadPool`) із задачами, що повертають результати через `std::future`, та перевіркою ефекту False Sharing.

---
